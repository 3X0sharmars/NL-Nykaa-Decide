## Related work, deliberately not in this repo

The discovery engine that produced Part 1 of the research — corpus retrieval,
the frozen codebook, the classifier bake-off and the validation gate — lives
separately under `Fashion/Apps/wishlist_discovery/`. It is a research pipeline,
not part of the deployed product, and shares no code with it.

Earlier UI prototypes (`Fashion/Apps/V2.0 MVP Nyra`, `Fashion/Apps/nykaa-wishlist`)
are superseded by `frontend/` and are kept only for history.
